# Sourabh Singh Portfolio — HTML + CSS

This is a static, three-page portfolio website. It uses HTML and CSS only; no JavaScript or framework is required.

## Pages
- `index.html` — Home page
- `3d-projects.html` — 3D project gallery. Each card opens a PDF in a new browser tab.
- `game-projects.html` — Game project descriptions and links.

## Add your images
Copy your image files into the folders below, keeping the filenames exactly as listed.

### `images/home/`
- `3d-category.jpg` — image for the 3D Projects home card
- `game-category.jpg` — image for the Game Projects home card
- `3d-banner.jpg` — wide banner background for the 3D page
- `game-banner.jpg` — wide banner background for the Game page

## Add your PDFs
Place the matching PDF files in `pdfs/`:
- `The-King.pdf`
- `Sheru.pdf`
- `Bholu.pdf`
- `Evil.pdf`
- `Warrior.pdf`
- `Eravath.pdf`
- `Skate-Park.pdf`
- `Farm-Asset.pdf`

The filenames in the `href` attributes of `3d-projects.html` must match the actual PDF filenames exactly. Uppercase/lowercase matters on many web hosts.

## Update your links
In the HTML files, replace the sample LinkedIn and itch.io homepage links with your actual profile URLs. In `game-projects.html`, replace each sample itch.io link with the corresponding game's actual itch.io page.

## Preview locally
1. Extract the ZIP.
2. Add your images and PDFs in the folders above.
3. Open `index.html` in a browser.
4. Click Home, Work, Contact, project cards, and game links to test them.

## Publish
Upload the complete `Portfolio` folder contents to your GitHub Pages repository. Keep the relative folder structure unchanged.
